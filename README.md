troubleshooting, incidentes, integrações, APIs, logs, conectividade,
monitoramento e infraestrutura.

Tenho bastante interesse em entender o que acontece **abaixo da aplicação**:
como serviços se comunicam, como identificar falhas através de logs,
como validar conectividade e como transformar procedimentos operacionais
repetitivos em ferramentas.

Foi daí que comecei a desenvolver minhas próprias **automações em Linux**,
criando ferramentas CLI para validação de infraestrutura, análise de
monitoramento e execução controlada de operações.

Atualmente direciono meus estudos para **Cybersecurity, DevOps, Redes,
Cloud e Segurança Defensiva**.

# `01 // F5 Operations CLI`

### Monitoramento, logs e troubleshooting em uma única interface

```bash
┌──(metalsec_kraken㉿linux)-[~/projects/f5-operations]
└─$ ./f5-ops.sh

[BOOT] Starting environment...

[##############################] 100%

[ OK ] Loading modules
[ OK ] Reading monitoring data
[ OK ] CLI ready

╭──────────────────────────────────────────╮
│          F5 OPERATIONS PANEL             │
├──────────────────────────────────────────┤
│ [1] Check UP / DOWN events               │
│ [2] Analyze logs                         │
│ [3] Search TCP monitors                  │
│ [4] Inspect monitor                      │
│ [5] Exit                                 │
╰──────────────────────────────────────────╯

ops@linux:~$ _
```

Ferramenta CLI desenvolvida em **Bash** para centralizar tarefas de
monitoramento e troubleshooting em ambientes **F5 BIG-IP**.

O objetivo foi transformar diferentes comandos e verificações realizadas
durante uma análise em uma interface única e interativa.

### `> features`

```yaml
monitoring:
  - TCP monitor discovery
  - UP / DOWN event filtering
  - individual monitor inspection

logs:
  - log filtering
  - status filtering
  - targeted searches

execution:
  - local execution
  - remote execution over SSH
  - TMSH integration

interface:
  - interactive menu
  - input validation
  - terminal feedback
```

### `> under_the_hood`

A ferramenta combina comandos Linux e funções Bash para:

```text
Logs
  │
  ├── grep
  │    └── status / events
  │
  └── filtering
       │
       ▼
     CLI Panel
       │
       ├─────────────┐
       ▼             ▼
   Monitoring       TMSH
       │             │
       ▼             ▼
 TCP Monitors     F5 BIG-IP
```

### `> stack`

`Bash` • `Linux` • `F5 BIG-IP` • `TMSH` • `SSH` • `Grep` • `AWK` • `Sed`

# `02 // Node Connectivity Validator`

### Parsing de configuração + descoberta + validação de conectividade

```bash
┌──(metalsec_kraken㉿linux)-[~/projects/node-validator]
└─$ ./node-validator.sh

[+] Loading configuration...

[ OK ] Configuration parsed
[ OK ] Nodes discovered
[ OK ] Primary endpoints loaded
[ OK ] Alternative endpoints loaded

────────────────────────────────────────────
 NODE        PRIMARY          ALT
────────────────────────────────────────────
 node-01     OK               OK
 node-02     OK               FAIL
 node-03     OK               OK
────────────────────────────────────────────
```

Ferramenta CLI criada para automatizar a **descoberta e validação de
nodes e endpoints de comunicação**.

Em vez de realizar verificações individualmente, o script interpreta
automaticamente um arquivo de configuração e transforma os dados encontrados
em uma estrutura utilizável pelo painel.

### `> pipeline`

```text
           Configuration File
                   │
                   ▼
              AWK Parser
                   │
                   ▼
        ┌─────────────────────┐
        │ Node                │
        │ Description         │
        │ Primary Endpoint    │
        │ Alternate Endpoint  │
        └──────────┬──────────┘
                   │
                   ▼
          Connectivity Check
                   │
              ┌────┴────┐
              ▼         ▼
             OK        FAIL
```

### `> features`

```yaml
parser:
  - automatic node discovery
  - description extraction
  - primary endpoint extraction
  - alternative endpoint extraction

validation:
  - host extraction
  - port extraction
  - connectivity testing

cli:
  - search by node
  - search by description
  - list all
  - validate all

filters:
  - OK only
  - FAIL only
  - all results
```

Também é possível selecionar individualmente qual comunicação testar:

```bash
Validation type:

[1] Primary
[2] Alternative
[3] Both

Select: _
```

### `> stack`

`Bash` • `AWK` • `Sed` • `Telnet` • `TCP/IP` • `Linux` • `Config Parsing`

# `03 // F5 Connection Automation`

### Automação controlada de operações de rede

```bash
┌──(metalsec_kraken㉿linux)-[~/projects/network-automation]
└─$ ./connection-ops.sh

Execution Mode: SSH

Available targets:

  1) TARGET_ALPHA
  2) TARGET_BETA
  3) TARGET_GAMMA
  4) TARGET_DELTA

Select targets:

> 1 3

Selected:

  + TARGET_ALPHA
  + TARGET_GAMMA

Confirm operation? [y/N]: _
```

Automação em **Bash** criada para simplificar a execução de operações
repetitivas relacionadas a conexões.

O script abstrai comandos operacionais em uma interface controlada,
permitindo selecionar múltiplos alvos antes da execução.

### `> execution flow`

```text
             START
               │
               ▼
        Load Operations
               │
               ▼
         Generate Menu
               │
               ▼
       Select Target(s)
               │
               ▼
        Validate Input
               │
               ▼
      Display Selection
               │
               ▼
       User Confirmation
               │
          ┌────┴────┐
          │         │
         YES        NO
          │         │
          ▼         ▼
       Execute     EXIT
          │
          ▼
     Process Target
          │
          ▼
         DONE
```

### `> engineering decisions`

```yaml
safety:
  - explicit confirmation before execution
  - invalid selection handling
  - controlled operation mapping

execution:
  - local mode
  - SSH mode
  - multiple target selection

automation:
  - reusable command function
  - dynamic target listing
  - sequential execution
  - execution feedback
```

### `> stack`

`Bash` • `Linux` • `SSH` • `F5 BIG-IP` • `TMSH` • `Network Automation`
